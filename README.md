# Video to Circle Telegram Bot

Бот для конвертации видео в «кружки» (Video Notes) с системой подписок, проверкой
участия в канале/чате, статистикой и админ-панелью.

## Возможности

- 🎬 **Максимальная поддержка форматов** — через ffmpeg (mp4, mov, avi, mkv, webm, flv, wmv, 3gp, ts, mts, vob и 30+ других)
- 🔄 **Конвертация в кружок** — авто-кроп в квадрат, масштабирование, H.264/AAC
- 💳 **Подписки Free / Pro** с оплатой через **Telegram Stars** (XTR)
- 🎥 **Качество на выбор** — Pro-пользователи выбирают разрешение (360/480/640)
- 🔐 **Проверка подписки** на канал/чат (админы проходят всегда)
- 📈 **Статистика** — пользователи, конвертации, ошибки, время обработки, топ форматов, платежи
- 📋 **Панель задач** — активные конвертации и фоновые задачи бота
- 🌐 **Языки** — русский и английский, переключение в меню
- 👑 **Полноценное меню** — inline-навигация для пользователей и админов
- 💬 **Только личные чаты** — в группах бот не отвечает
- 🐳 **Docker** — готовый к развертыванию образ

## Быстрый старт

```bash
cp config.example.yaml config.yaml
# укажите bot.token и bot.admin_ids в config.yaml
docker compose up -d --build
docker compose logs -f
```

`config.yaml` в `.gitignore` — реальные токены в репозиторий не попадают.

## Конфигурация

**Единственный источник статических настроек — `config.yaml`** (переменные окружения не используются).
Динамика (подписки, статистика, ссылка на канал) хранится в SQLite (`/app/data/bot_data.db`).

```yaml
bot:
  token: "123456:ABC..."     # токен от @BotFather
  admin_ids: [123456789]     # ID администраторов

default_language: "ru"       # ru | en — язык новых пользователей

channel:
  invite_text: "Вступить в канал"

plans:                       # тарифы
  free:
    max_size_mb: 50          # макс. размер исходного видео
    max_duration_sec: 60     # макс. длительность
    resolutions: [360]       # доступные разрешения кружка
    default_resolution: 360
    crf: 24                  # качество (меньше = лучше)
    preset: "fast"
    daily_limit: 5           # конвертаций в день (0 = без лимита)
  pro:
    max_size_mb: 200
    max_duration_sec: 60
    resolutions: [360, 480, 640]
    default_resolution: 480
    crf: 20
    preset: "medium"
    daily_limit: 0

prices:                      # цены в Telegram Stars (XTR)
  - {code: "pro_30d",  plan: "pro", days: 30,  stars: 100}
  - {code: "pro_90d",  plan: "pro", days: 90,  stars: 250}
  - {code: "pro_365d", plan: "pro", days: 365, stars: 800}

logging:
  level: "INFO"
```

## Меню

### Пользовательское (inline)

- 🎬 **Как пользоваться** — инструкция и список форматов
- 💳 **Подписка** — текущий тариф, лимиты, покупка/продление Pro за ⭐
- 📊 **Мой профиль** — ID, тариф, качество, счётчики конвертаций
- ⚙️ **Настройки** — язык; для Pro — выбор качества
- ℹ️ **Помощь**

### Админское (inline, видно только админам)

- 📈 **Статистика** — пользователи, конвертации, ошибки, среднее время, топ форматов, платежи, срез по дням
- 👥 **Пользователи** — всего/новых + последние зарегистрированные
- 📋 **Задачи** — активные конвертации и фоновые задачи (запуски, последний запуск)
- ⚙️ **Настройки бота** — режим обслуживания, проверка подписки (вкл/выкл)
- 📢 **Канал** — текущая ссылка и инструкция по смене

## Команды

| Команда | Кто | Описание |
|---------|-----|----------|
| `/start`, `/menu` | все | Главное меню |
| `/help` | все | Справка |
| `/setlanguage` | все | Сменить язык |
| `/admin` | админ | Админ-меню |
| `/stats` | админ | Статистика |
| `/tasks` | админ | Активные и фоновые задачи |
| `/finduser <ID\|@username>` | админ | Поиск пользователей |
| `/setchannel <ссылка>` | админ | Установить канал проверки подписки |
| `/channel` | админ | Показать текущий канал |
| `/clearchannel` | админ | Отключить проверку подписки |

### Форматы ссылок на канал/чат

- `@username` — публичный канал/чат
- `-1001234567890` — числовой ID
- `https://t.me/username` — ссылка на публичный канал/чат
- `https://t.me/c/1234567890` — приватный канал/чат по ID

## Подписки и оплата

- **Free** — базовое качество (360p), лимит конвертаций в день.
- **Pro** — повышенное качество (до 640p на выбор), больший размер файла, без лимита.
- Оплата — **Telegram Stars**: пользователь выбирает срок в «💳 Подписка», бот
  выставляет счёт (`currency=XTR`). После оплаты подписка активируется, продление
  суммируется к текущей дате окончания. Платежи идемпотентны по `charge_id`.

## Фоновые задачи

| Задача | Период | Что делает |
|--------|--------|-----------|
| `expire_subscriptions` | 10 мин | Помечает просроченные подписки неактивными |
| `cleanup_temp` | 30 мин | Удаляет временные файлы конвертации старше 1 часа |
| `daily_stats` | 1 час | Пишет снимок статистики в лог |

Статус задач виден админу в «📋 Задачи».

## Архитектура

```
├── main.py              # Точка входа: конфиг, БД, роутеры, фоновые задачи
├── context.py           # Общий контекст (config, repos, tasks, jobs)
├── config_loader.py     # Загрузка config.yaml → Config/Plans
├── config.yaml          # Все статические настройки (в .gitignore)
├── config.example.yaml  # Пример конфига
├── db.py                # Схема SQLite и подключение
├── repositories.py      # Репозитории: users, subscriptions, usage, settings, channel, payments
├── plans.py             # Тарифы: лимиты, разрешения, определение прав
├── access.py            # Проверки: роль, тариф, членство, обслуживание
├── i18n.py              # Загрузка локалей и функция t()
├── locales/ru.json      # Русские тексты
├── locales/en.json      # Английские тексты
├── menus.py             # Inline-клавиатуры
├── handlers_user.py     # Пользовательские хендлеры
├── handlers_admin.py    # Админские хендлеры
├── payments.py          # Telegram Stars (invoice, payload)
├── tasks.py             # TaskRegistry + JobRunner
├── video_converter.py   # Конвертация через ffmpeg
├── channel_checker.py   # Проверка участия в канале/чате
├── requirements.txt
├── Dockerfile
└── docker-compose.yml
```

## Требования к серверу

- Docker 20.10+ / Docker Compose 2.0+
- 512 MB RAM (рекомендуется 1 GB)
- 1 vCPU
- ffmpeg внутри контейнера (уже включён)

## Ограничения Telegram для кружков

- ⏱ Макс. длительность: ~60 секунд
- 📐 Разрешение: квадрат (до 640×640)
- 📦 Размер файла: настраивается тарифом
- 🎞 Кодек: H.264, AAC аудио
