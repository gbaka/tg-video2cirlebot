# Video to Circle Telegram Bot

Бот для конвертации видео в «кружки» (Video Notes) с проверкой подписки на канал/чат.

## Возможности

- 🎬 **Максимальная поддержка форматов** — через ffmpeg (mp4, mov, avi, mkv, webm, flv, wmv, 3gp и 30+ других)
- 🔄 **Конвертация в кружок** — автоматический кроп в квадрат, масштабирование до 360x360, кодирование в H.264/AAC
- 🔐 **Проверка подписки** — бот отказывает в работе, если пользователь не в канале/чате
- 👑 **Админ-панель** — смена канала проверки командой `/setchannel` (ссылка хранится в SQLite)
- 💬 **Только личные чаты** — в группах бот не отвечает
- 🐳 **Docker** — готовый к развертыванию образ

## Быстрый старт

### 1. Настройте config.yaml

```bash
cp config.example.yaml config.yaml
```

Откройте `config.yaml` и укажите:
- `bot.token` — токен от @BotFather
- `bot.admin_ids` — список ID администраторов

Никаких переменных окружения не требуется — всё в одном файле.
`config.yaml` добавлен в `.gitignore`, поэтому реальные токены не попадут в репозиторий.

### 2. Запустите через Docker Compose

```bash
docker compose up -d --build
```

### 3. Проверьте логи

```bash
docker compose logs -f
```

## Конфигурация

**Единственный источник настроек — `config.yaml`.** Переменные окружения (`.env`) не используются.

```yaml
bot:
  token: "123456:ABC..."     # токен от @BotFather
  admin_ids: [123456789]     # ID администраторов

channel:
  invite_text: "Вступить в канал"   # текст кнопки вступления

video:
  max_size_mb: 50            # макс. размер исходного видео
  target_resolution: 360     # разрешение кружка
  crf: 24                    # качество кодирования
  preset: "fast"             # пресет кодирования

logging:
  level: "INFO"
```

Ссылка на канал/чат для проверки подписки в `config.yaml` **не хранится** — она задаётся командой `/setchannel` и сохраняется в SQLite (`/app/data/bot_data.db`).

### Форматы ссылок на канал/чат

- `@username` — публичный канал/чат
- `-1001234567890` — числовой ID
- `https://t.me/username` — ссылка на публичный канал/чат
- `https://t.me/c/1234567890` — приватный канал/чат по ID

## Команды

### Пользовательские

| Команда | Описание |
|---------|----------|
| `/start` | Начало работы, краткая справка |
| `/help` | Подробная помощь (для админов — со списком админ-команд) |

### Админские (скрыты от обычных пользователей)

| Команда | Описание |
|---------|----------|
| `/setchannel <ссылка>` | Установить канал/чат для проверки подписки |
| `/channel` | Показать текущий канал/чат |
| `/clearchannel` | Отключить проверку подписки |

## Архитектура

```
├── main.py              # Точка входа, хендлеры
├── config_loader.py     # Загрузка конфига (только YAML)
├── config.yaml          # Все настройки
├── storage.py           # SQLite хранилище ссылки на канал
├── video_converter.py   # Конвертация через ffmpeg
├── channel_checker.py   # Проверка подписки
├── requirements.txt     # Python зависимости
├── Dockerfile           # Многоэтапная сборка
└── docker-compose.yml   # Развертывание
```

## Требования к серверу

- Docker 20.10+ / Docker Compose 2.0+
- 512 MB RAM (рекомендуется 1 GB)
- 1 vCPU
- ffmpeg внутри контейнера (уже включен)

## Ограничения Telegram для кружков

- ⏱ Макс. длительность: ~60 секунд
- 📐 Разрешение: 360x360 (квадрат)
- 📦 Размер файла: до 50 MB (настраивается)
- 🎞 Кодек: H.264 (Baseline/High), AAC аудио
